## 🚀 QUICK START (5 Steps)

```bash
# 1. Install dependencies
pnpm install

# 2. Create upload folders
mkdir -p uploads/{profile,team,products,documents,organization}

# 3. Terminal 1: Seed demo data
pnpm seed

# 4. Terminal 2: Start frontend (port 3000)
pnpm dev

# 5. Terminal 3: Start backend (port 5000)
pnpm server:dev
```

Then visit: **http://localhost:3000**
